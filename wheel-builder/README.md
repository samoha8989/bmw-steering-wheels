# Русский конструктор рулей

Визуальные материалы и карты освещения: Miami Carbon Designs, используются по разрешению, о котором сообщил владелец сайта. Исходные URL записаны в import-manifest.json и fallback-manifest.json. Русский интерфейс, состояние конфигурации, расчёт каталожной цены «от» и черновик заявки Telegram реализованы для BMW Steering Wheels.

Модели: BMW F-Series M Performance, Mercedes-AMG Performance, Mercedes-Benz (дизайн 2024+), Mercedes-Benz (дизайн 2019+). Внутренний ID mercedes-2015 сохранён из структуры исходных материалов; это не утверждение о годах совместимости. Совместимость по модели автомобиля не рассчитывается.

Доступные формы, материалы, LED и лепестки определены отдельно для каждого дизайна в models.json. Превью статичное; сохранение в PNG 1254×1254. Две отсутствующие карты заменены готовыми исходными изображениями для всех 77 цветов. Цены и платежи Miami не перенесены. Цена «от» берётся из catalog.json по F-серии либо Mercedes с учётом подогрева. Стоимость конкретного набора деталей уточняет менеджер. Форма заявки открывает черновик в Telegram владельца; автоматических отправок нет.

Точка входа: ../wheel-builder.html?model=bmw-fseries. Для BMW G используется отдельный согласованный ../g-builder.html. Общий выбор: ../index.html#/build. Серверы Miami во время работы опубликованного конструктора не используются: все файлы локальны.
