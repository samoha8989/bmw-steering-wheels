# Сайт BMW Steering Wheels — как это устроено

Главная и каталог (`index.html`, `studio.js`) — одностраничное приложение. Для поисковиков рядом лежат **статические страницы**:

| Адрес | Что это |
|---|---|
| `/ruli/` | хаб: все марки и кузова |
| `/ruli/bmw-f30/` и т. п. | страница кузова (одна на строку, например «F30 / F31 / F35») |
| `/ruli/bmw-f-kuzov/`, `bmw-g-kuzov/`, `bmw-e-kuzov/` | общие страницы серий |
| `/ruli/mercedes/`, `/ruli/porsche/` | марки |
| `/rul/<номер>/` | страница каждого руля (если номер повторяется у «в наличии» и «под заказ» — `f01-stock`, `f01-order`) |

Страницы **не правятся руками**: их создаёт скрипт из `catalog.json`.

## Как пересобрать страницы (после изменения каталога)

```bash
cd site_clone/site
python3 build_pages.py     # пересобрать страницы, sitemap.xml, robots.txt, stats-config.js
python3 check_site.py      # проверить ссылки, JSON-LD, уникальность title/description
```

Нужен Python 3 и пакет Pillow (`pip3 install pillow`). Список кузовов лежит в начале `build_pages.py` (словарь `BODIES`, он повторяет `MODELS` из `studio.js`). Цены, сроки и условия берутся из `catalog.json` и текстов сайта; в `build_pages.py` условия доставки/предоплаты написаны в функциях `delivery_block` и `body_paragraphs` — при изменении условий поправьте там.

После пересборки закоммитьте и отправьте на GitHub (`ОПУБЛИКОВАТЬ_САЙТ.command` в корне проекта).

## Настройки — `site.config.json`

- `site_url` — адрес сайта. **Единственное место**, где он записан (canonical, sitemap, Open Graph, robots).
- `yandex_verification` — код из Яндекс Вебмастера (только сам код из `content="…"`).
- `metrika_id` — номер счётчика Яндекс Метрики (цифры).
- `stats_endpoint` — адрес сборщика статистики (оканчивается на `/exec`).

После любого изменения: `python3 build_pages.py`. Пути к CSS, картинкам и ссылкам между страницами **относительные**, поэтому при смене домена они продолжают работать.

## Свой домен .ru на GitHub Pages — по шагам

1. Купите домен у регистратора (например, reg.ru, nic.ru, timeweb).
2. В `site.config.json` замените `site_url` на `https://ваш-домен.ru` (без слэша в конце) и выполните `python3 build_pages.py`.
3. Создайте в папке сайта файл `CNAME` без расширения, внутри одна строка: `ваш-домен.ru` (без https://). Закоммитьте и отправьте.
4. У регистратора откройте DNS-записи домена и добавьте:
   - четыре записи **A** для имени `@` (корень домена): `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись **CNAME** для имени `www` со значением `samoha8989.github.io`.
   (Актуальные адреса GitHub: docs.github.com → Pages → «Managing a custom domain».)
5. На GitHub: репозиторий → Settings → Pages → в поле **Custom domain** впишите `ваш-домен.ru` → Save. Подождите, пока пройдёт проверка DNS (от минут до суток).
6. Когда проверка пройдена, поставьте галочку **Enforce HTTPS**.
7. В Яндекс Вебмастере добавьте новый домен, подтвердите права (код в `yandex_verification`), укажите главное зеркало и отправьте `sitemap.xml`. В Метрике замените адрес сайта. Старый адрес github.io начнёт перенаправлять на новый.

**Важно про robots.txt.** Поисковики читают `robots.txt` только в корне домена. Пока сайт на `samoha8989.github.io/bmw-steering-wheels`, этот файл не работает как robots; со своим доменом заработает. До этого карту сайта отправьте в Вебмастер вручную, а закрытие `stats.html` держится на `noindex` внутри страницы.

## Статистика

- Работает **только после согласия посетителя** (плашка в `consent.js`). Без согласия ничего не собирается и Метрика не загружается. Плашка показывается, когда заполнен `stats_endpoint` или `metrika_id`.
- Собственный сборщик: `stats-server/Code.gs` (Google Apps Script + Google Таблица). Пароль админки **в коде и в репозитории не хранится**: он задаётся в Apps Script → Настройки проекта → Свойства скрипта → `ADMIN_KEY`.
- Страница `stats.html`: пароль, `noindex`, Disallow в robots, на сайте ссылок на неё нет. Пароль хранится только в сессии вкладки.
- Что считается: посещения, источники (Instagram, Авито, Яндекс, Telegram, прямые), какие рули и кузова смотрят, клики «Заказать в Telegram», выбор в конструкторе, страницы кузовов (`ruli/…`).
- Если сборщик недоступен (например, не работает сервер), сайт работает как обычно: события копятся в памяти и отправляются позже, лишние отбрасываются.

### Подключить сборщик (один раз)
1. Создайте Google Таблицу → Расширения → Apps Script → вставьте `stats-server/Code.gs`.
2. Настройки проекта → Свойства скрипта → добавьте `ADMIN_KEY` = длинный пароль (12+ символов).
3. Начать развёртывание → Веб-приложение → «Запуск от имени: я», «Доступ: все» → скопируйте адрес `…/exec`.
4. Впишите адрес в `site.config.json` → `stats_endpoint`, выполните `python3 build_pages.py`, отправьте на GitHub.
5. Откройте `…/stats.html`, введите пароль.
