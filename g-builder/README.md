# Конструктор BMW G — локальная версия, 06.11.2026

Визуальные материалы Miami Carbon Designs используются по разрешению, о котором сообщил владелец сайта. Перенесены только публичные файлы статичного превью BMW G. Источники каждого изображения и размеры записаны в import-manifest.json. Чужие цены, совместимость, формы, платежи и аналитика не перенесены.

Вход: ../g-builder.html либо выбор BMW G в основном конструкторе. Только круглая форма. Материал хвата: перфорированная кожа, гладкая кожа, алькантара; цвет чёрный. Верх/низ: три материала и три карбона. Накладка: штатная + три карбона. Подушка: штатная, гладкая кожа, алькантара; цвет чёрный. 19 цветов строчки по зонам, 77 оттенков метки (один оранжевый). Подогрев. Лепестков нет.

Слои WebP хранятся локально. Цвет строчки и метки изменяется по исходным маскам; материал подушки — по исходным картам освещения и калибровке. Строчка ограничивается альфа-каналом материала. Подложка исходного превью чёрная. Фото сохраняется в PNG 1254×1254. Состояние не сохраняется между заходами, есть сброс. Цена «от» — прежняя схема по catalog.json, heated/unheated; стоимость кастомных деталей уточняется менеджером. CTA формирует черновик Telegram, отправок при проверке не было.

Новый русский интерфейс и логика: app.js/app.css. material-renderer.js адаптирован из публичного сборочного JS Miami; функции оплаты и сторонняя аналитика отсутствуют. Импорт: ../builder_tools/miami/import_g.py относительно site_clone, требует исходный JS в /tmp/miami-builder-main.js. Текущие файлы полностью самостоятельны и не требуют повторного импорта.

Проверки: 18 сочетаний хвата/верха-низа, 19 цветов строчки хвата, 77 меток, все накладки и подушки, подогрев, сброс, скачивание PNG, переход из общего конструктора; браузер 1280×720 и 390×844. Ошибок консоли не наблюдалось. Скриншоты и checks.json: site_clone/builder_tools/miami/qa.
